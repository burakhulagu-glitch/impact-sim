# B3D Malzeme ve Darbe

Tarayıcıda çalışan iki program:

* **MC (Material Creator) 3.8.0**: mikromekanik ve homojenizasyon
* **IS (Impact Simulator) 2.6.0**: düşük hızlı darbe ve sıcaklık etkisi, MC ile birleşik

Çevrimiçi sürüm: https://burakhulagu-glitch.github.io/impact-sim/

Kurulum gerekmez; bütün hesaplar tarayıcıda yapılır. Yerelde kullanmak için depoyu indirip `index.html` dosyasını bir yerel sunucu üzerinden açın (örneğin `python -m http.server`).

MC, BS ve IS programları yapay zekâ desteğiyle oluşturulmuştur.
